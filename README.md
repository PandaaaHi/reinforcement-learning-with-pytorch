# Reinforcement-learning-with-pytorch
Reinforcement-learning-with-pytorch, inspired by [MorvanZhou](https://github.com/MorvanZhou/Reinforcement-learning-with-tensorflow). To adapt to the running environment of the older version, it is recommended to create a virtual environment based on Python 3.6 using conda, and install the following packages:
- gym=0.16
- matplotlib=3.3.4
- numpy=1.19.5
- pandas=1.1.5
- torch=1.10.2
